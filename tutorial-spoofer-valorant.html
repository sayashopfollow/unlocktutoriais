O tutorial do spoffer é o mais complexo que temos, exige atenção para que tudo seja feito da exata forma ensinada, pois se algum passo for esquecido ou feito na ordem ou forma errada, você não vai conseguir remover seu ban!

A senha de todos arquivos criptografados é 123

⚠ Execute todos os aplicativos e drivers como ADMINISTRADOR

1º passo - Formate o Computador

(Obrigatório formatar para o Windows 10 Versão Pro)

TUTORIAL DE COMO FORMATAR O PC

FERRAMENTA USADA NO VÍDEO

⚠ IMPORTANTE:
  • Mantenha-se OFFLINE! Não faça login na sua conta Microsoft.
  • Pule ou recuse todas perguntas de privacidade durante a formatação
  • Não faça login no OneDrive, Geforce Experience, ou Logitech G Hub (Pode baixar os drivers mas não faça login em nada)

2º passo - FLASH BIOS

⚠ Recomandamos realizar 2 flashs

Você vai precisar alterar a versão da sua BIOS
Tutorial de como fazer o Flash em algumas placas:
Asus - Asrock - Gigabyte - Lenovo - MSI - Aorus - Biostar

Se sua placa não está aqui procure um tutorial no YouTube

Se a sua placa não tem compatibilidade com o flash faça o seguinte:
Remova a pilha da placa por 15 minutos depois insira novamente

⚠ Após terminar o 1º flash faça o processo mais uma vez para ter certeza

Após fazer os 2 flashs, inicie o windows normalmente

3º passo - Config da BIOS

Após terminar o flash, volte na BIOS e:
- Ative o SecureBoot [Enable no modo Standard]
- Ative a Virtualization/SVM Mode
⚠ Desative o TPM 2.0
- Aperte F10 para salvar e iniciar o Windows
- Assim que o Windows iniciar, pesquise por Isolamento de Núcleo e ative-o!
- Por fim reinicie o computador mais uma vez para aplicar a modificação

4º passo - Config do Windows

  • DESATIVE o IPv6
  • Baixe e Instale o Winrar (necessário para extrair os arquivos)
  • Desative os Antvirus e Windows Defender
  • Desativador do Windows Defender
  • Bloqueie o Windows Update
  • Baixe e Instale os drivers obrigatórios

Após completar o 4º passo REINICIE O COMPUTADOR OBRIGATÓRIO

5º passo - Spoffer

⚠ IMPORTANTE:

Baixe seus drivers de internet ANTES de usar o spoffer
(não será obrigatório usar mas caso seja necessário você precisa ter!)

Você usa Internet via Cabo ou Wifi ?

  • Internet via Cabo DRIVER INTERNET CABO
  • Internet Wifi OPÇÃO 1 OPÇÃO 2 OPÇÃO 3

Após baixar os drivers de internet, mantenha-os guardados!
Caso seja necessários após usar o Spoffer

Hora de Spoffar

Baixe o Serial Checker DOWNLOAD SERIAL CHECKER
Execute o app HWID como ADMINISTRADOR
Um CMD irá abrir mostrando seus seriais, salve tirando print ou copiando as informações
(Vamos precisar checar as informações depois de spoffar)

Baixe o spoffer DOWNLOAD SP0FFER
Extraia usando o Winrar
Execute o spoffer como ADMINISTRADOR e use sua key para se registrar
Assim que se registrar, use a opção Spoffer
Após concluir, reinicie o computador e use o Serial Checker HWID novamente para comparar os seriais antigos com os novos
Caso todos seriais estejam diferentes significa que o spoffer funcionou, baixe o Valorant
Após finalizar a instalação do jogo, reinicie o computador para iniciar o Vanguard
Quando iniciar abra o spoffer antes de entrar no jogo e use a opção TPM SPOFFER
VOCÊ VAI PRECISAR USAR A OPÇÃO TPM SPOFFER SEMPRE ANTES DE ENTRAR NO JOGO
Após usar o TPM SPOFFER é só entrar no jogo e aproveitar
