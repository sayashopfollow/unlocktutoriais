CENTRAL DE SETUP

Siga rigorosamente as etapas abaixo para garantir a execução limpa e indetectável do software.

01
PREPARAÇÃO DO SISTEMA
  1. Abra o Segurança do Windows.
  2. Acesse Proteção contra vírus e ameaças.
  3. Entre em Gerenciar configurações.
  4. Desative as proteções ativas durante o processo de instalação e principalmente o uso..
02
VISUAL C++ REDISTRIBUTABLE

Baixe o pacote compilado com todas as bibliotecas necessárias:

DOWNLOAD — VISUAL C++ ALL-IN-ONE
  1. Efetue o download do pacote comprimido.
  2. Extraia os arquivos do formato .zip ou .rar.
  3. Abra o diretório onde os arquivos foram extraídos.
  4. Execute o utilitário install.bat como Administrador.
03
INICIALIZAÇÃO DO EMULADOR

Faça o download da versão mais recente do cliente:

DOWNLOAD — CLIENTE EMULADOR (SENHA 123)
  1. Extraia a pasta contida no arquivo baixado.
  2. Navegue até o diretório do emulador.
  3. Execute o arquivo .exe principal.
  4. Insira a sua KEY DE ACESSO quando solicitado.
  5. Inicie o jogo normalmente.

Guia Visual Completo

Assista ao guia visual completo para instalação, regras e uso do produto.

ATENÇÃO DE PERMISSÃO: Sempre execute todos os arquivos e o emulador clicando com o botão direito e selecionando "Executar como Administrador" para evitar travamentos de privilégio no sistema.
